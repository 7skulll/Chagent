# 网页与工作区设计

合并自原《网页对话设计》与《工作区与文件编辑器实施方案》。两份文档描述的功能都已交付（F1–F5），本文只保留**当前生效的界面契约、接口、数据归属与限制**；执行能力另见[统一可编程执行契约](统一可编程执行契约.md)，证据见[验收记录汇总](验收记录汇总.md)。

2026-11-05 补充：页面内目录浏览只覆盖当前挂载根；从页面输入另一个宿主绝对路径会走已关闭的跨宿主切换接口并收到 503。当前数据库以容器路径标识工作区，不能通过重挂载实现任意宿主目录切换。稳定宿主工作区身份与目标交互见[自主建站整体方案](宿主执行方案.md)。

## 1. 定位与启动

本地单用户 Agent 的网页入口：FastAPI 提供 REST + SSE，前端是原生 HTML/CSS/JavaScript，无打包步骤、无前端框架。复用现有 `AgentRunner`、会话仓储、模型适配器和 PostgreSQL，不另建聊天循环。

```sh
uv sync
uv run --env-file .env python -m chagent          # 默认 http://127.0.0.1:8765
./scripts/start.command                            # 双击启动，自动加载项目 .env
```

启动器做三件事：端口被占用时顺延；同端口已有本应用则只开浏览器、不起第二个进程；开始监听后自动打开浏览器（`--no-open` 关闭）。`--workspace` 指定起始目录，默认 `~/Chagent Workspace`。

网页只接受容器内的可执行组合（A 或 D），本机 `configured` 档启动会被拒绝；`--demo` 是无真实模型的诊断入口，只提供只读工具面。

## 2. 分层

| 模块 | 职责 |
|---|---|
| `web/__main__.py` | 解析配置、`--host` / `--port`、启动单个 Uvicorn worker |
| `web/app.py` | 应用生命周期、`/api` 主路由、本地访问边界、静态资源 |
| `web/runtime.py` | 工作区范围、托管运行任务、后台记忆 worker |
| `web/schemas.py` | Pydantic 请求/响应契约与边界校验 |
| `web/workspace_api.py` | 工作区、文件服务、输出确认 |
| `web/file_api.py` | 文本读写、预览、下载 |
| `web/memory_api.py` | 长期记忆 CRUD 与审核 |
| `web/static/` | `index.html`、`main.js`（模块入口）、`app.js`、`file-editor.js`、`core/dom.js`、`core/api.js`、`markdown.js`、`style.css` |

数据库连接池与模型 HTTP 客户端在启动时创建；关闭时先取消生成任务，再释放资源。

## 3. 接口

### 3.1 会话与运行

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/info` | 工作区、供应商、模型、三轴、`programmable` |
| GET | `/api/config` | 生效的执行轴、审批、联网、压缩、预算、工具数；密钥只回 `set`/`missing` |
| GET | `/api/sessions` | 指定工作区的会话分页；`archived` 默认 `hide`，`q` 只搜标题 |
| POST | `/api/sessions` | 创建会话（不接受 `mode`） |
| PATCH | `/api/sessions/{id}` | 改标题或归档/恢复 |
| GET | `/api/sessions/{id}` | 会话信息与 `latest_run` |
| GET | `/api/sessions/{id}/messages` | 历史消息，带 `superseded_by` |
| GET | `/api/sessions/{id}/sources` | 每个 run 实际注入的长期记忆 |
| GET | `/api/sessions/{id}/context` | 摘要版本与最近三次上下文快照 |
| POST | `/api/sessions/{id}/runs` | 发消息；也支持 `regenerate_from` 与 `edit_message_id` |
| GET | `/api/runs/{id}` | 运行状态；等待审批时投影 `waiting_for=approval` |
| GET | `/api/runs/{id}/events` | SSE，支持 `Last-Event-ID` |
| GET · POST | `/api/runs/{id}/approvals`、`/api/approvals/{id}/decide` | 待审批命令与决策 |
| POST | `/api/runs/{id}/cancel` | 取消运行 |
| GET | `/api/runs?active=true` | 当前工作区未收敛的运行 |
| POST | `/api/uploads?name=&workspace=` | 原始字节上传到工作区 `uploads/` |
| GET | `/api/usage`、`/api/sessions/{id}/usage` | token 用量（只报 token，不报金额） |

### 3.2 工作区与文件

统一前缀 `/api/workspaces/{workspace_id}`：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/entries?path=&offset=&limit=&hidden=` | 单层目录，返回 `next_offset` |
| POST | `/entries` | 新建文件/目录，不覆盖 |
| GET | `/text?path=` | UTF-8 内容、`version`、`identity`、换行信息 |
| PUT | `/text` | 带版本与身份保存，冲突 409 |
| POST | `/rename` | 原子 no-replace 重命名 |
| POST | `/trash` · `GET /trash` · `POST /trash/{record}/restore` | 回收与恢复 |
| GET | `/content?path=` | 附件下载，最大 20 MiB，不作为静态目录暴露 |
| POST · GET | `/outputs` | 生成/另存为意图与恢复 |
| GET | `/outputs/{id}`、`/outputs/{id}/proposal` | 状态与待写入提案下载 |
| POST | `/outputs/{id}/decision` | `overwrite` / `keep-both` / `cancel` |

选择目录本身不针对某个工作区，因此不带 `workspace_id`：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET · POST | `/api/workspaces` | 历史工作区（含不可用原因）与打开一个目录；打开即登记，不撤销 |
| POST | `/api/workspaces/switch-host` | 跨宿主目录自动切换暂时关闭，固定返回 503；等待工作区身份迁移 |
| POST | `/api/workspace-picker` | 系统目录弹窗；返回 `native_picker=false` 表示本机没有可用的系统弹窗，页面改用下面的浏览接口 |
| GET | `/api/workspace-browse?path=&after=` | 在 `CHAGENT_WORKSPACE_ROOT`（未设置时为用户主目录）之内按目录名分页浏览；每页最多 200 项，`next_after` 非空时可加载下一页 |

浏览接口只做发现：不登记、不打开、不产生任何状态；请求目标 `resolve` 后必须落在根目录之内，越界、不存在、不是目录一律 400。列表中的越界符号链接标为不可用。此接口会向本地网页披露根目录内的文件夹名称，范围大于此前只显示已登记工作区的接口；不要把敏感目录挂入该根目录。

### 3.3 预览

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/preview?path=` | 类型、版本、页数或尺寸；不支持时返回原因与下载入口 |
| GET | `/preview/page?path=&version=&page=` | 校验版本后输出单页 PNG |
| GET | `/file-state?path=` | 只查身份与大小，二进制标签轮询用 |

请求体限制：普通 JSON 64 KiB，`/api/workspaces/` 前缀 6.4 MB，上传 20 MiB（客户端与服务端各拦一次）。校验错误统一映射为 HTTP 400，不回显 Pydantic 的 `input`/`ctx` 或请求正文。`/openapi.json` 与本地 `/docs` 由路由生成，资源只来自 `/static`，不加载 CDN。

## 4. 流式事件与运行生命周期

发送消息时先持久化用户消息与运行记录，再返回 202 与 `run_id`；生成任务由 `WebRuntime` 持有，不依附于发送请求或 SSE 连接。每个会话由数据库唯一约束保证至多一个活跃运行。

SSE 先注册版本通知，再按序读 `run_events`（每批 ≤200），提交后通知唤醒，1 秒兜底轮询，等待新事件时不占数据库连接。前端使用 `model_started`、`text_delta`、`tool_started`、`tool_completed`；遇到 `run_completed`/`run_failed`/`run_cancelled`/`run_interrupted` 即发 `end` 关闭流。约 15 秒一次注释心跳。

记忆提取事件追加在 `run_completed` 之后，属于运行之外的记账；SSE 在终态关闭，所以前端单独轮询 `/memory-job`（最多 2 分钟，切会话即停）。因此**直接读事件表时"最后一条是终态"不成立**，消费方要以终态事件为界。

刷新时读取历史并重放仍在进行的运行；助手输出只由 SSE 渲染，避免与历史重复。停止会取消 Runner 任务、记录终态、把进行中的工具标记为结果未知；重复停止不会再次中断落库。页面断开不取消生成；服务正常关闭会取消其托管的运行。`localStorage` 只保存当前会话、工作区与侧栏折叠状态。

## 5. 对话侧的四条约定

**渲染**：固定子集——标题 h1–h4、列表（一层嵌套）、引用、表格、围栏代码、行内代码、链接、粗体、斜体。安全模型只有一条：`markdown.js` **先整体转义再识别结构**，所以输出里每个标签都是它自己写的模板；不支持内联 HTML（答案是模型生成的不受信文本）；链接在正则层限定 `http(s)://`，带 `target="_blank"` 与 `rel="noopener noreferrer"`。流式渲染按 `requestAnimationFrame` 节流；贴底跟随、上翻停跟、右下角"回到最新"；超 2000 字折叠到 8 行。

**重新生成与编辑重发**：历史只追加，替换不改写旧行，只写 `superseded_by`（迁移 `0016`）。退休的是**一个后缀**而不是一个点；回放过滤 `superseded_by IS NULL`，阅读不过滤，界面把旧记录折起来可展开对照；重新生成不写新的用户消息，`RunState.current_input` 取最近一条用户消息。失败重试复用同一路径。

**来源**：回答下方"依据"折叠块，三路来源——`web_search` 的 `results`（标题/站点/摘要/日期）、`read_file` 解析 PDF/Word/Excel 时的 `citations`（页码/标题路径/工作表名）、`/sources` 返回的注入记忆。三路都在 `details` 里，而 `details` 按契约**不进模型上下文**。不做正文 `[1][2]` 自动标注。

**上传**：左下 **＋**、拖拽、粘贴三个入口进同一队列，一次一个文件。按后缀分流（PDF/Word/Excel/文本），其他类型当场拒绝而不是先传后失效；图片只存不解析；失败可重试且不清空已输入文字；上传成功的可读文件合成一句"请阅读 uploads/a.pdf"放进输入框。

## 6. 本地边界

服务仅本机单用户：绑定回环地址、限制 Host、拒绝跨 Origin 与 cross-site 请求、不启用 CORS。所有查询限定在"已打开的工作区"集合内。静态资源用固定白名单（`/static` 只服务列表里的文件，不做目录读），路由取 `/static/{name:path}` 以容纳模块子目录，准入仍只由白名单字典决定——`../app.py`、`core/../app.py`、`uploads/x.txt` 实测均 404。CSP 的 `default-src`/`script-src`/`style-src` 都是 `'self'`，`img-src` 额外允许 `data:`（缩略图用 data URL）。

页面入口是 `main.js`（`type="module"`），它按原顺序 `import "./app.js"` 与 `"./file-editor.js"`；`markdown.js` 仍是经典脚本，因为它同时被 Node 端 `require()` 加载。模块脚本对 MIME 敏感：白名单内的 `.js` 必须返回 `text/javascript`，否则浏览器拒绝加载，而 `type="module"` 的加载失败表现为空 DOM 且无任何报错。`tests/test_web_ui.py` 因此从 `index.html` 出发沿相对 `import` 递归走模块图，断言每个可达路径都在白名单内且文件存在。

当前一个 Chagent 服务进程可打开同一挂载根内的多个子目录工作区；不同宿主根的动态执行容器尚未实现。运行不进入分布式队列，不做多进程接管或崩溃后自动恢复。强制杀进程可能遗留 `running` 记录，不能通过网页接管。

## 7. 工作区导航（F1）

- 左侧按工作区分组会话，组内有"＋ 新对话"；未选择目录时先选目录再聊天。
- 同一真实路径复用同一工作区 ID；不同路径的同名目录分开显示，用父目录辅助区分；**不按名称重绑**。
- 打开历史会话会同步切换工作区与右侧文件树；搜索默认只搜当前工作区。
- 打开目录有三个入口，行为一致：系统目录弹窗（仅 macOS 接入）、页面内文件夹浏览（容器入口走这条，根目录是挂载的 `/workspaces`）、手工输入路径。
- 容器内的手工输入也只能打开当前挂载根中的目录；输入其他宿主绝对路径不会被静默映射或自动重启容器，而是收到 503。目标行为见[自主建站整体方案](宿主执行方案.md)。
- 系统弹窗只负责“问一次”：`native_picker=false` 时页面直接展开文件夹浏览，不把用户刚做的操作变成一条报错；弹窗存在但被拒绝（权限、无显示会话）时保留错误原因并同时展开浏览。
- 取消选择不产生任何状态变化。目录失效（删除/移动/无权限）保留条目并显示原因，标题不可点击；重新进入时重新准入，不把历史登记当永久通过。
- 迁移 `0018` 记录最近打开时间；"从列表移除"不删除原目录。

## 8. 文件树与编辑器（F2/F3）

**文件树**：按层展开、分页、隐藏文件开关；默认隐藏 `.git` 等内部目录，`.chagent`（回收站与内部状态）永不显示、不可访问；符号链接显示为不可打开的项，不跟随读写或递归删除。

**文本编辑**：多标签（按工作区 ID + 相对路径隔离，上限 25 个），UTF-8、1 MiB 上限；代码/Markdown/TXT/JSON/CSV 均按文本处理（CSV 不是表格软件）；Markdown 可切换安全预览；混合换行的文件只读，避免 `<textarea>` 归一化破坏原文件。

**草稿与保存**：输入只改草稿，保存或 `⌘S` 才写盘；标签显示 `●`；关闭脏标签、跨工作区切换、删除/重命名涉及草稿时提供"保存 / 放弃 / 取消"；刷新或关闭触发浏览器离开提示，但**不承诺崩溃后恢复草稿**。切换同一工作区的聊天不丢草稿。

**版本与冲突**：读取返回内容哈希与文件身份，保存必须携带；冲突保留草稿并给"查看磁盘版本 / 另存为 / 确认覆盖"，确认覆盖仍绑定最新版本，文件随后再变仍拒绝。外部变更在窗口重新获得焦点、手动刷新、以及可见页面每 5 秒检查；干净标签可自动重载，脏标签只提示。目录树不每 5 秒重绘（避免夺走焦点）。

**管理操作**：新建文件/目录（父目录必须已存在）、原子 no-replace 重命名（macOS `renameatx_np`、Linux `renameat2`，其他平台明确拒绝而非降级）、删除进 `.chagent/trash/<UUID>/` 并可恢复；恢复撞名保留现有文件。浏览或编辑文件**不会**自动把内容注入模型。

## 9. 预览（F5）

PDF 用独立解码进程按页栅格化为 PNG，不把原 PDF 放进 iframe、不执行文档脚本；支持翻页、页码输入、缩放、适应宽度。图片重编码为 PNG，GIF/WebP 只显示首帧，尊重 JPEG EXIF 方向。PDF/图片是只读标签，不能保存或另存为。

限额：输入与下载 20 MiB、PDF ≤2000 页、栅格最长边 1600px、图片 ≤3200 万源像素、栅格最长边 2400px、缩放 25%–400%。解码进程只收到已校验的字节、清空继承环境、最多两个并发、排队超 2 秒返回可重试 503。

预览不等于模型能力：不做 OCR，不做图片正文理解，扫描 PDF 也读不出文字。

## 10. Agent 写入、输出与同名确认（F4）

- Agent 与手动编辑复用同一 `FileService`/`WorkspaceFS`：路径、身份、原子替换、工作区进程内写锁一致；只读工具不参与该锁（并发屏障测试覆盖）。
- `versioned_files` 打开后，改已有文件必须带读取 SHA256；`apply_patch` 的 `versions` 对全部已有目标先校验再提交。
- 上传落 `uploads/`；生成默认落工作区根或指定已有子目录；`create_directory` 只建一层，`create_file` 不隐式创建父链。
- 撞名走宿主确认：无撞名直接写盘；撞名返回 pending 且文件不变，模型 run 正常结束、不占执行槽、不自动续跑。确认卡刷新后可恢复，24 小时有效，token 绑定工作区/路径/内容/已有哈希/身份，重复提交只成功一次，期间文件变化则 409 并轮换 token。
- 新输出不再写 `generated_files`；旧表保留历史下载，"保存到工作区"才导出且撞名同样确认。会话产物列表同时展示磁盘输出与旧历史产物。
- 边界：Shell 与外部程序不参与文件服务的锁，通用命令覆盖**不会**弹这个确认卡；不宣称跨进程文件事务，取消 run 不回滚已写文件。

## 11. 布局与响应式

三栏：左侧工作区/会话，中间聊天，右侧文件面板（文件树 + 标签 + 编辑/预览，另有上下文与历史产物页签）。左中、中右可拖动分隔线，文件树与编辑区之间可调高度，比例在本机记忆；960px 以下侧栏、1180px 以下文件面板降级为遮罩抽屉，两个抽屉互斥，可用遮罩/关闭按钮/Escape 关闭。

输入框随多行内容增高（56–220px），Enter 发送、Shift+Enter 换行；空消息不可发，上传中禁发。新建、重命名、恢复、另存为走页面内表单，不依赖浏览器 `prompt`。

## 12. 数据归属

- 文件内容只在源目录，数据库不保存目录镜像。
- 数据库保存：`workspaces`（含最近打开时间）、`sessions`、`messages`、`runs`/`run_events`、`model_calls`/`tool_calls`、摘要与工具产物、长期记忆与 `memory_jobs`、`approval_requests`、`file_outputs`/`file_operations`，以及旧的 `generated_files`。迁移到 `0019`。
- 布局比例、展开目录、打开的标签属于本机界面状态，**不能当作工作区授权**。
- 确认记录与回收信息按工作区隔离，刷新后可恢复。

## 13. 验证方式

```sh
NO_PROXY=127.0.0.1,localhost CHAGENT_TEST_DATABASE_URL=postgresql:///chagent \
  PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -q
```
