## 文档维护规则

- 当前行为写专题，未来工作只排在实施计划，交付证据写实施记录/验收记录；不另起版本号路线图。
- 写清实现、自动测试、真实工具、真实模型浏览器和真实项目分别验证了什么。
- 模式开关与工具注册、执行隔离与请求路径保护分别陈述，不能互相推定。
- 历史数字标日期；测试跳过不计通过，合成 fixture 不计真实项目。
- 删除旧计划时先迁移仍有效的决策并修复引用；保留支持结论的原始数据。
- 同一批交付只留一份记录：实现契约与该批证据写在同一条目里，不再按子批次各起一份。
