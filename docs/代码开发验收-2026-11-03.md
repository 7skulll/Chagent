## 验收中发现并修复

首轮 isolated 设置 PYTHONSAFEPATH=1，模型反复排查普通项目导入。最终 run_tests 在沙箱内部显式设置当前工作区 PYTHONPATH，使用独立字节码路径并禁写字节码；exec 工具说明相应约束。只设置外层 child_env 无效，因为 Sandbox.wrap 内部还会 env -i 重置；已把测试变量放到隔离内部，真实测试覆盖该路径。

快速等长修改可能命中旧 pyc，测试读到旧断言；独立缓存路径和禁写已修复。自动测试明确保留这一反例。

模型首轮若干进度为英文；有一次回复用含糊的“5 passed →”描述导入失败，另一次对后台进程状态的概括未反映 run 结束后的清理。以原始工具、数据库和进程核对为准，不把模型叙述当作验收证据。语言与精确表达仍是后续改进项。
