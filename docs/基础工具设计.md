# 基础工具调用设计与实现

## 现有工具

| 工具 | 主要参数 | 行为 |
|---|---|---|
| list_dir | path、offset、limit | 列出一层目录，按名称分页，标识目录与符号链接 |
| read_file | path、offset、limit | 读取 UTF-8 文件，返回行号、分页位置与 SHA-256 |
| write_file | path、content、overwrite、expected_sha256 | 创建文件；覆盖必须显式声明 |
| edit_file | path、old_text、new_text、expected_sha256 | 原文必须恰好匹配一次，返回改动 diff |
| exec_command | cmd、workdir、timeout_ms、max_output_chars | 单次非交互宿主命令，返回退出码、输出与耗时 |

Echo 保留用于验证链路。真实模型可以自行选择工具；`--demo` 或显式 `--tool` 使用固定响应模型测试工具协议，后者不具备自然语言选择工具的能力。模型配置见[模型配置](模型配置.md)。

## 调用链

```text
Runner 从数据库取得会话工作区
  → 创建本次 ToolContext（工作区、会话 ID、运行 ID）
  → ToolScheduler 提交整批 queued 意图，分组并等待工作区屏障和并发额度
  → 提交 running 状态
  → ToolExecutor 校验 JSON Schema、上下文与宿主执行开关
  → 具体工具执行
  → AgentToolResult（模型文本、结构化详情、错误与结果未知标记）
  → 保存工具结果、结果消息和事件
  → 下一轮模型请求
```

工具实例不保存当前工作区，避免不同会话相互污染。模型参数不包含可信的工作区根路径，也不能开启宿主执行开关。

工具的声明与执行实现保持关联；`declaration()` 仅向模型暴露名称、说明与输入 schema。Runner 负责模型循环；ToolScheduler 负责批次调度、记录与消息顺序回填；文件和命令实现不直接操作数据库。

## 文件操作规则

- 相对路径相对于会话工作区；允许指向同一工作区内部的绝对路径。
- 拒绝 `..` 和工作区外路径。工作区根路径初始化时规范化；根目录以下的符号链接不跟随。
- 当前使用 POSIX 目录描述符与 `O_NOFOLLOW` 遍历路径，支持 macOS/Linux；Windows 尚未实现。
- 仅支持常规 UTF-8 文件，单文件及写入内容上限 1 MiB；目录不会递归读取。
- 文件工具保留受文件大小与行分页限制的完整结果；超过 8000 个 UTF-8 字节时由持久化层保存产物，上下文使用摘录与引用。分页位置和文件摘要仍保留。
- 写入在同目录准备临时文件并原子替换；新建采用不覆盖已有文件的发布方式，失败时清理临时文件。
- 默认不覆盖现有文件；编辑时内部再次检查读取时的摘要。调用方可以提供 `expected_sha256`，拒绝根据旧版本生成的编辑。
- 文件工具不会自动创建父目录，也不提供删除或重命名操作。

摘要检查能发现已发生的内容变化，但不是与所有外部编辑器之间的原子比较交换协议。同一 Runner 对相同规范化工作区提供读组／独占修改屏障；只读文件操作在线程中执行。跨进程、外部写入者及重叠工作区的冲突处理仍待扩展。详见[运行与工具调度](运行与工具调度.md)。

## 命令执行规则

借鉴 Codex 的单次命令执行路径，当前只实现 `/bin/sh -c`、工作目录、超时、输出边界和进程清理，不提供 PTY、交互 stdin 或后台 session。

- 默认不注册 `exec_command`。用环境变量 `CHAGENT_ALLOW_HOST_COMMANDS=true` 或命令行 `--allow-host-commands` 显式启用。
- 执行器另外检查宿主执行开关，防止仅注册工具就绕过设置。
- 初始工作目录必须位于会话工作区，但命令本身拥有宿主进程的文件、网络与环境访问权限；这不是操作系统沙箱。
- 子进程 stdin 关闭，stdout/stderr 合并；默认等待 10 秒，上限 30 秒。
- 默认最多捕获 1 MiB 输出；显式 max_output_chars 最大仍为 64000。使用字节上限实现保守限制，超出部分持续排空并标记截断。大结果保存为产物，模型可通过 read_artifact 分页读取。
- 为命令创建独立进程组。超时与取消时终止进程组并回收子进程；主动脱离该组的进程不属于可靠管理范围。
- 非零退出码作为错误结果返回。超时可能已经产生副作用，因此标为 `outcome_unknown`，数据库记录为 `unknown`，不自动重试。

更完整的沙箱、权限审批、后台进程与增量输出归档不在本次范围。

## 运行示例

以下均经过原有 Runner 与数据库记录链路：

```sh
uv run --env-file .env python -m chagent --tool list_dir --arguments '{}'
uv run --env-file .env python -m chagent --tool read_file --arguments '{"path":"README.md","offset":1,"limit":40}'
uv run --env-file .env python -m chagent --allow-host-commands --tool exec_command --arguments '{"cmd":"printf hello","timeout_ms":1000}'
```

`--workspace` 仅在创建新会话时选择工作区；使用 `--session` 继续会话时始终从数据库恢复其原工作区。
