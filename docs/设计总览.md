# 设计总览

2026-11-05 更新：自主建站入口为宿主主控 + 每工作区容器，网页可切换任意已存在宿主目录；`site` 管理跨 run 网站，原生命令在同页一次性审批后执行。真实 Python、Java、已有项目修复（第一交付）已完成验收；真实模型的网页批准链路已验收，第二交付的交互输入与恢复故障演练仍待完成；前端模块化已完成。旧 seatbelt 已删除，方案 A 宿主终端代理和下文按 work/code 模式描述的内容属历史设计。当前状态见[宿主执行方案](宿主执行方案.md)。

Chagent 是单用户 Agent：浏览器负责对话和查看记录，Python 进程推进「模型 → 工具 → 模型」，PostgreSQL 保存消息、请求、工具调用、事件与任务状态。没有多人账户或分布式队列；当前可在本机或整进程容器中运行。

## 历史产品与模式（2026-11-03，已失效）

> 当前形态：单一统一工具面，网页只接受容器内的可执行组合（A/D），`sessions.mode` 仅为读取旧数据保留。以下 work/code 段落只作历史对照，不代表当前行为。

默认入口是本地网页，默认 work；满足 isolated、工作区禁写、命令断网和宿主命令开启的配置可使用只读代码分析。显式 trusted-development 已支持可写 code，无需逐项审批；命令保持 isolated 断网，交互 stdin 尚未开放。完整交互审批不作为普通可写编码的前置条件，下一步验证真实项目，见[实施计划](实施计划.md)。

**模式分离且可在聊天区切换**：新建会话时选类型，之后可用标题旁的开关通过 `PATCH /api/sessions/<UUID>` 在 work 与 code 间切换。切换只影响之后的 run；进行中的 run 持空闲锁拒绝切换，因为它的工具面在开始时已声明给模型。切到 code 前跑与 code 会话相同的隔离预检，`CHAGENT_CODE_MODE=off` 的构建直接 409，不降级。历史里另一模式的工具记录保留为记录，不改写。

模式决定宿主执行能力；普通网页 work 允许文件创建、编辑、补丁与目录创建，可写 code 另加命令执行。显式只读 code 会同时裁掉写工具与 create_file。生产网页文件修改携带读取版本；生成、上传和另存为撞名走持久化宿主确认。手动编辑独立于会话模式与归档状态。`GET /api/config` 分别显示 work 写入与 code 写入能力，不能只看 mode 名推定权限。

| 方向 | 当前行为 |
|---|---|
| work 读取 | 文件检索、文本/PDF/Word/Excel 读取、工具输出产物分页 |
| work 写入 | `write_file`／`edit_file`／`apply_patch`／`create_directory` 与可写 code 共有，网页编辑检查读取版本 |
| work 交付 | 工作区文本输出与下载；同名输出需确认，旧数据库产物保留历史下载 |
| 工作区与文件 | 分组导航、文件树、多标签编辑与手动保存、版本冲突处理、回收站恢复、上传与输出确认；PDF 分页与 PNG/JPEG/GIF/WebP 缩放预览，范围与证据见 F5 验收 |
| 对话 | Markdown、来源、上传、重新生成/编辑重发/重试、流式与历史恢复 |
| 联网 | 默认关闭，开启后使用 DeepSeek Search/Fetch；长页支持 find/offset |
| 上下文 | 预算、完整轮次、摘要、保留式压缩、大输出产物化、长期记忆 |
| 只读 code | isolated 工作区禁写、命令断网；命令/测试与长进程 read/stop；真实项目范围见只读验收记录 |

工具面在注册和执行两层约束，每个 run 固定所属会话的 mode；隐藏按钮不构成权限。演示模型/确定性探针是单独装配，不与生产能力等同。

系统提示不再自动注入工作区路径、目录树、Git 状态或 AGENTS.md；需要的事实由工具读取。旧历史、摘要或记忆仍可能含真实路径。路径隐藏和请求出口保护尚未完成。

## 模块地图

| 模块 | 职责 |
|---|---|
| `domain/` | 消息、运行、会话、上下文、摘要、记忆等数据与校验 |
| `agent/` | 模型循环、RunState、预算、取消、流式写入 |
| `context/` | 预算选择、消息投影与 token 估算、分段、摘要与压缩；environment 模块保留但不自动注入 |
| `models/` | OpenAI 兼容、Anthropic、固定响应模型及流式协议 |
| `tools/` | 声明/执行/调度、文件检索与编辑、产物、联网、审批、命令/进程；sandbox 退化为容器边界的描述与判定 |
| `hostexec/`、`tools/host.py` | 默认关闭的方案 A 原型：宿主终端确认与一次性命令申请；尚非正式自主建站能力 |
| `execution.py` | 三轴推导与合法组合校验的唯一入口；配置、网页门禁、CLI 与工具装配共用 |
| `documents/` | 可选 PDF/Word/Excel 解析，统一文本块、位置与哈希缓存 |
| `memory/` | 检索注入、显式记忆、候选提取和进程内 worker |
| `storage/` | psycopg 连接池、原生 SQL、迁移、仓储、事件/记忆队列 |
| `web/` | FastAPI、SSE、工作区与文件上传、配置查看 |
| `web/static/` | 无构建前端：`views/` 一列一个视图、`render/` 纯呈现、`run/` 事件归约与唯一渲染入口、`core/` 基础件；依赖只向下，见[网页与工作区设计 2.1](网页与工作区设计.md#21-前端模块边界2026-11-05-交付) |
| `sessions/`、`cli.py` | 本地管理与冻结的一次性/确定性诊断入口 |
| `bootstrap.py` | 显式依赖装配、统一工具面与确定性诊断面 |

目标是 domain 保持纯数据，网页负责协议而非执行策略。工作区校验已移至 `boundaries.py`，网页、CLI、Runner 与工具共用；`web/workspaces.py` 只保留兼容导入。执行轴的推导与校验集中在 `execution.py`，网页准入、CLI、Runner 与工具装配读同一结果；命令的 HOME/tmp 按 run 独立，进程回收后释放。work/code 分离与 R1–R5 只读交付保留为历史设计。

## 一次运行

```text
网页/CLI → 校验会话与执行边界 → 建 run、用户消息与 run_started
  → 加载历史、任务状态、有效摘要、失败恢复注记 → RunState
  → ContextManager 预算/摘要 → MemoryService 注入参考记忆
  → 保存模型请求与快照 → 流式模型调用 → 保存完整响应
  → 若有工具：调度/审批 → 执行 → 按调用次序提交结果和事件 → 下一轮
  → 结束或失败/取消：清理 run 所属进程 → 保存终态
  → 已完成回答按策略入 memory_jobs → 后台 worker 独立提取
```

`/remember` 是确定性短路：命中合法命令时直接处理并保存确认，不发模型请求。自动记忆提取不阻塞回答；自动摘要是在需要压缩时进入主请求准备阶段，不能与后台记忆提取混为一谈。

关键不变量：

- 状态与关键事件同事务；通知在提交后发送。消息与工具结果先持久化，再进入活动视图。
- 历史正文只追加，替换写 superseded_by 使旧后缀退休；阅读保留，模型回放过滤。
- 每个 run 只有一个任务推进模型循环；工具可按声明并行，结果按原调用顺序提交。
- 失败运行的已提交事实可作为宿主注记回放，未知副作用标 unknown，不宣称成功也不自动重做。
- 租约/令牌避免旧拥有者写入；取消、超时和崩溃不承诺回滚文件或命令副作用。

## 持久化与前端

业务数据包括 sessions/task_states/messages、runs/run_events、model_calls/tool_calls、摘要与工具产物、长期记忆与 memory_jobs、approval_requests，以及生成文件 generated_files。另有 file_outputs 确认意图及 file_operations 来源记录。迁移已到 0021（含宿主工作区绑定与旧路径隔离），见[数据库配置](数据库配置.md)。

前端是静态 HTML/CSS/JavaScript，无打包步骤，入口 `main.js` 以原生 ES modules 组织，依赖只向下（`main → views → render → run → core`，`markdown.js` 保持经典脚本），跨模块调用无页面全局。侧栏、聊天与文件编辑/上下文/历史产物面板可折叠，比例可调；PDF 分页与图片缩放预览使用版本校验的独立进程栅格化，不自动注入模型；Markdown 先转义，链接限制 http(s)。上翻后流式和结束刷新都保留阅读位置，贴底时跟随；长回答可展开。具体行为与局限见[网页对话设计](网页与工作区设计.md)。模块边界与三条永久护栏见[网页与工作区设计第 2.1 节](网页与工作区设计.md#21-前端模块边界2026-11-05-交付)。
