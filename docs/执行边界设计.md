# 执行边界契约

更新：2026-11-02。本文只描述当前实现；后续顺序见[实施计划](实施计划.md)。历史 S/K/J/W 的设计推演、试验与回退见[实施记录](实施记录.md)，macOS isolated 的授权清单与证据见[code 模式执行隔离](code模式执行隔离.md)。

## 模式与入口

| 能力 | work | code |
|---|---|---|
| 工作区读取与检索 | 允许 | 允许 |
| 数据库存储的会话专属文本下载 | `create_file`，不改工作区 | 当前不注册 `create_file` |
| 工作区写入/编辑/补丁 | 不注册 | 构建开关启用时注册 |
| 命令/测试/进程 | 不注册 | 宿主命令开关开启时才注册；生产模型还要求 isolated |
| 网页搜索/抓取 | 由独立 web 开关控制 | 同左，不受命令断网控制 |

网页是当前产品入口，只接受 work，明确拒绝 `CHAGENT_CODE_MODE=on`。底层 code 工具存在不等于网页已经支持。工具按注册表裁剪，执行器再次检查参数、上下文和宿主执行开关。每个 run 在开始时固定会话的工具面。

网页、CLI 和 isolated 策略目前会校验源码目录边界，但检查尚未统一到所有程序入口；统一策略是下一批工作。确定性 demo/`--tool` 使用不同装配，不能当作真实模型的权限证据。

## 工作区与文件

- 相对路径从会话工作区解析；根以下使用 POSIX 目录描述符和 no-follow 操作，拒绝父目录穿越与越界绝对路径。
- 网页拒绝程序源码目录、其子目录和包含它的父目录，旧不合规会话保留数据但不可在网页访问。
- isolated 命令额外拒绝与运行时重叠的工作区及预先存在的多硬链接文件，每次准备执行都检查；普通文件工具尚无同等的全入口硬链接策略。
- 这些限制不防范同一系统账户主动改写应用、复制源码或替换运行时。虚拟 `/workspace` 与供应商请求出口检查尚未交付，详见[源码保护方案](源码保护与工作区隔离方案.md)。

## 沙箱档位

| 档位 | 文件读取 | 写入 | 环境/HOME | 命令网络 |
|---|---|---|---|---|
| off | 宿主权限 | 宿主权限 | 继承 | 宿主权限 |
| workspace-write（旧诊断档） | 通常可读工作区外文件，仅定向禁读凭据路径 | 工作区及配置的用户临时目录 | 继承 | 默认拒绝 outbound，可配置 |
| isolated（macOS） | 工作区、私有 scratch、明确运行时白名单 | 工作区、私有 scratch、`/dev/null` | 白名单环境、合成 HOME/tmp | 默认拒绝；network=true 拒绝 |

生产 `create_runner` 在 code+宿主执行组合下必须配置 isolated，否则构造失败。新隔离档只接受 seatbelt；后端缺失、启动失败或必要探针失败均拒绝，不自动降级。旧档仍供显式诊断，不能作为 code 读取隔离的证据。

权限由宿主配置决定，模型只能请求已注册工具。审批不能扩大沙箱权限，profile 失败也不能通过“用户同意”自动改成 off。

私有 scratch 当前按 Sandbox 实例和工作区共享，关闭实例清理；不是每个 run 或会话独立。会话间归属及入口统一仍需收口。

## 审批

当前 `ApprovalPolicy` 覆盖 `exec_command` 与 `run_tests`，**不覆盖 `process write`**；后者是 C3 的已知缺口。

| 策略 | 当前行为 |
|---|---|
| never | 不询问；当前配置默认值，不代表未来 code 产品默认值 |
| on-request | sandbox=off 时询问；已受配置沙箱限制的执行不询问 |
| untrusted | 对覆盖的宿主工具询问，精确前缀 allowlist 匹配时除外 |
| on-failure | 明确拒绝，不实现失败后提权重试 |

allowlist 按 token 前缀匹配，含 shell 控制符的命令不命中。它不是 shell 安全分析器，也不保证某个程序无副作用。

单次授权绑定 run、工具参数指纹和 cwd；参数或目录变化不能复用，消费后失效。审批记录持久化在 `approval_requests`，等待者不占工具执行槽或工作区写屏障。等待使用运行活动预算暂停；绝对审批超时仍生效。

网页确认卡/CLI 提问与 broker 使用同一决策。网页无订阅者超过宽限（默认 10 秒）时以 unwatched 拒绝；多标签只要仍有订阅者就不视为离线。重启不复用内存中的等待者或进程句柄。

C3 将补充 stdin 字节/EOF、进程身份、拒绝不写入和取消边界。不能把“初始命令获批”当作任意后续输入获批。

## 命令、测试与长进程

- `exec_command` 默认一次等待 10 秒，上限 30 秒；不带 yield 时 stdin 关闭、输出有界，退出码如实返回。
- `run_tests` 默认 120 秒、声明上限 300 秒；执行器按请求预算增加清理余量（10 秒），默认工具预算上限 310 秒，可配置。进程墙钟必须为正，timeout=0 不表示无限。
- `yield_time_ms` 将进程交给本 run 的 `ProcessManager`，返回进程 ID；后续 `process read/write/stop` 操作只允许本 run 的句柄。
- 单次 read 最多 20,000 字符，窗口默认保留最近 1 MiB；绝对游标与 gap 区分未读、已读和已丢弃输出。
- 每 run 默认最多 4 个活进程，默认墙钟 600 秒；没有 PTY、重启接管或超窗输出归档。
- isolated 档对一次性 exec、测试和会话进程统一清空启动环境并应用 profile；后代继承内核策略。
- 正常结束、失败、取消和超时在写 run 终态前回收所属进程组。主动脱离进程组的后代不是可靠回收保证，不能据 killpg 宣称控制任意后台守护进程。

会话进程让出后，调度器调用锁会释放，进程可能与后续文件操作并行；这不是跨进程文件事务。完整状态契约见[运行与工具调度](运行与工具调度.md)。

## 联网是独立能力

`CHAGENT_WEB_ACCESS=off|deepseek` 管理 agent 进程内的 `web_search` 和 `web_fetch`，与模型供应商独立。搜索 Key 优先 `CHAGENT_SEARCH_API_KEY`，缺失时回落到 `DEEPSEEK_API_KEY`，诊断只显示来源变量名。

- 搜索每次最多 8 条，转发最多 8,000 字符、每条摘要最多 700 字符；站点/日期等搜索语法原样传给供应商。
- Fetch 返回 Markdown，每次正文最多 20,000 字符（默认 12,000），`find` 定位、`offset` 分页，返回 next_offset。全文按无 fragment 的 URL 缓存 300 秒，最多 16 页；这是工具实例缓存，可能跨 run 复用。
- HTTP 响应受 4 MB 检查约束；当前为完整读取后检查，不承诺下载到达上限时立即截断流。搜索/抓取超时分别 15/32 秒。
- 不执行 JS、不登录、不截图；私有地址拒绝由供应商执行，本机不能审计完整地址策略。历史回环与 metadata 地址探针为 403，不代表所有私网地址均已逐一测试。
- 返回内容是第三方资料，不是授权或系统指令。抓取成功也不保证目标段落已被模型阅读；需检查 find/分页结果与引用证据。

网页工具的出网发生在 agent 进程，命令 seatbelt 不覆盖它。命令网络授权属于 C4，当前 isolated 仍拒绝 network=true，不因搜索开关而放开命令网络。

## 故障与证据

- 未知工具、参数错误和工具执行错误可作为普通结果交回模型，不擅自提权或重放副作用。
- `unknown` 表示结果无法确认，不表示“没有执行”；数据库回滚也不会回滚文件/命令副作用。
- 运行租约与令牌防止旧 worker 写入，不能替代操作系统权限边界。
- 隔离验证必须同时证明正常 shell/Python/工作区操作能成功和越界操作确实被拒。后端启动失败、网络无监听器或测试跳过均不能算隔离通过。
- 最新 macOS 合成探针 14 项通过，实际 Shell/Git/Python 测试/长进程通过；真实项目及其他工具链未验收。证据在[执行隔离记录](code模式执行隔离.md)，产品开放条件以[实施计划](实施计划.md)为准。
