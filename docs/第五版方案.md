## code 模式开放门槛

1. 沙箱隔离有可复现的正反向证据，默认配置与失败行为明确。
2. 命令执行及交互进程写入都经过适当审批，授权范围和生命周期可解释。
3. 工具超时与拒绝的语义清晰，长测试和长任务可按声明工作并在结束时回收。
4. 子进程不继承未授权的密钥，HOME 与敏感路径隔离有验证。
5. 真实项目回归完成，失败和跳过项得到处理。
6. 每种拒绝和不可用状态有可区分的提示，不静默降级。
