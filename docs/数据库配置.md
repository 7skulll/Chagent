# PostgreSQL 配置

自主建站入口在本机运行主控，连接 Compose PostgreSQL 的本机回环端口 5433；随机 `CHAGENT_DB_PASSWORD` 只保存在被 Git 忽略的本机 `.env`，工作区容器不能读取。项目使用 psycopg 异步连接池和原生 SQL，不增加 ORM。旧本机诊断入口仍可通过本地 Unix socket 连接另一个数据库。

**工作区身份（2026-11-05）**：迁移 `0020` 建立宿主路径、设备号与 inode 绑定和原生执行/网站状态表；`0021` 将无法证明宿主来源的旧 `/workspaces` 行标记为 `rebind_required`。原生执行的 `unknown` 状态在 `0020` 的约束里，主控启动时把遗留 `starting` 标为 `unknown` 而不重放（`57358da`）。`0022` 加入交互式原生进程：`interactive`／`process_id`／`child_pid`、状态 `running`，以及以单次写入批准为主键的 `native_stdin_writes`。`0023` 给 `approval_requests` 加 `batch_id`／`batch_index`，让同一模型轮次的多条写审批共享一次页面决策。这些历史会话只能通过只读审计接口查看，不能在新工作区执行。新宿主主控以规范化宿主路径识别工作区，不以容器路径 `/workspaces` 识别。原 Compose 数据库迁移前已有备份，见[验收记录](验收记录汇总.md#14-宿主主控自主建站2026-11-05)。

## 本地启动

```sh
uv sync
# 仅在数据库尚未存在时执行
createdb chagent
cp -n .env.example .env
uv run --env-file .env python -m chagent.storage check
uv run --env-file .env python -m chagent.storage migrate
```

`.env` 不提交到版本控制。程序从环境变量读取配置，使用 `uv run --env-file .env` 加载文件；从其他启动器运行时需由启动器注入环境变量。

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| CHAGENT_DATABASE_URL | postgresql:///chagent | 数据库连接信息 |
| CHAGENT_DB_POOL_MIN_SIZE | 1 | 最小连接数 |
| CHAGENT_DB_POOL_MAX_SIZE | 4 | 最大连接数 |
| CHAGENT_DB_TIMEOUT | 5 | 获取连接的超时秒数 |

连接池上限与后台提取并发相关：每个提取 worker 在读写时占用一个连接，因此 `CHAGENT_MEMORY_WORKER_CONCURRENCY` 至多为 `CHAGENT_DB_POOL_MAX_SIZE - 1`（单连接池除外），否则 worker 可能占满连接池，让并发运行在 `db_timeout` 后失败。该组合在启动时校验，不等到运行期超时。

连接远程或要求密码的数据库时，在本地 `.env` 配置连接地址。不要把密码写入源代码或提交到仓库。

## 使用方式

```python
from chagent.config import Settings
from chagent.storage.database import Database

async with Database(Settings.from_env()) as database:
    async with database.transaction() as connection:
        await connection.execute("SELECT 1")
```

`connection()` 默认自动提交单条 SQL；需要原子执行多条语句时使用 `transaction()`，并在整个操作中传递同一个连接。异常或取消时回滚，成功时提交。一个 Database 实例在一个应用事件循环内使用，关闭后重新创建实例。

## 迁移

迁移 SQL 位于 `src/chagent/storage/migrations/`，按文件名排序执行。新增变更时添加下一个编号的 SQL，不修改已应用文件。

迁移过程使用 PostgreSQL 事务锁串行化，并记录名称和 SHA-256 校验和。重复执行不会重新建表；已应用文件被修改或数据库版本比代码更新时拒绝继续。迁移由命令显式执行；单次运行与网页启动时也会自动应用尚未执行的迁移。

| 迁移 | 内容 |
|---|---|
| `0001_core.sql` | workspaces、sessions、runs、messages |
| `0002_execution.sql` | model_calls、tool_calls、run_events |
| `0003_sessions.sql` | 会话更新时间与归档时间、`task_states` |
| `0004_context_summaries.sql` | `session_summaries`、`compaction_calls` |
| `0005_long_runs.sql` | 摘要的来源运行与被保护输入引用、`tool_artifacts` |
| `0006_memories.sql` | memories、memory_revisions、memory_extractions |
| `0007_run_end_reasons.sql` | `runs.end_reason` 及状态／原因匹配约束 |
| `0008_tool_scheduling.sql` | `tool_calls.call_index` 与批次内序号回填 |
| `0009_memory_jobs.sql` | `memory_jobs` 提取队列 |
| `0010_run_ownership.sql` | 运行所有权令牌与租约到期时间 |
| `0011_memory_job_claims.sql` | 记忆任务的领取令牌，防止过期 worker 覆盖新尝试 |
| `0012_explicit_memory_end_reason.sql` | 终态约束允许 `completed` 携带 `explicit_memory` |
| `0013_repeated_tool_call_end_reason.sql` | repeated_tool_call 失败终态 |
| `0014_approvals.sql` | approval_requests，审批状态与单次消费 |
| `0015_session_mode.sql` | sessions.mode，work/code 约束 |
| `0016_message_supersession.sql` | messages.superseded_by，保留替换历史 |
| `0017_generated_files.sql` | 旧会话/run 归属的文本下载历史 |
| `0018_workspace_navigation.sql` | 最近打开工作区时间 |
| `0019_file_outputs.sql` | 文件输出意图、确认状态/单次 token、操作来源记录 |
| `0020_host_controller.sql` | 宿主工作区路径/设备号/inode 绑定、原生执行与网站状态表 |
| `0021_legacy_workspace_quarantine.sql` | 无法证明宿主来源的旧 `/workspaces` 行标记 `rebind_required` |
| `0022_native_interactive.sql` | 交互式原生进程：`interactive`／`process_id`／`child_pid`、`running` 状态、`native_stdin_writes` 单次写入审计 |
| `0023_approval_batches.sql` | `approval_requests.batch_id`／`batch_index`：一次页面决策覆盖同一模型轮次的多次写入，每行仍保留自己的指纹与核销 |

模型请求同时保存上下文快照，工具执行前保存调用意图。消息正文使用 JSONB，保留现有消息类型结构；外键约束防止消息引用其他会话的运行，唯一索引限制每会话最多一个排队或活动运行。数据库不替代 Runner 的生命周期管理。任务状态通过修订号实现并发更新检查；摘要检查点与启用事件同事务提交；记忆按作用范围维护活动键唯一。

## 检查

```sh
# 本机有 HTTP 代理时会拦截回环请求，测试前先放行
NO_PROXY=127.0.0.1,localhost CHAGENT_TEST_DATABASE_URL=postgresql:///chagent \
  uv run python -m unittest discover -s tests -q
```

未指定测试地址时，非数据库测试仍会执行，数据库集成测试跳过。指定后，每个集成测试创建独立临时 schema（`chagent_*_test_<hex>`），测试后清理；不改动业务表数据。测试数据库用户需要创建 schema 的权限。

集成检查覆盖迁移并发与重复执行、校验和、事务提交／回滚／取消、JSONB 往返、会话关联与活动运行约束、摘要检查点、记忆版本冲突，以及提取队列的领取、租约回收、重试上限和领取令牌失效后的写入拒绝。

连接池生命周期参考 [psycopg 官方文档](https://www.psycopg.org/psycopg3/docs/advanced/pool.html)。
