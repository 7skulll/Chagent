# B1 实施前事务审计

状态：审计进行中，B1 尚未实施。

当前运行状态的写入分布在 Runner、RunRepository、ToolScheduler、ContextManager、SummaryRepository 与 MemoryService。后台记忆任务也会在运行终态后追加事件，因此不能简单地在所有事件写入处要求运行仍为 running，否则会破坏记忆处理。

必须覆盖的主运行写入包括：模型开始与响应、文本事件、工具排队／开始／结果、摘要检查点、运行终态及终态事务中的显式记忆和记忆入队。审批尚未实现，不应为它提前改变状态集。后台记忆任务需要独立的任务所有权检查；当前 MemoryJob 的完成操作只按 job ID 和 running 状态更新，没有绑定领取令牌，旧 worker 在租约回收后仍可能覆盖新尝试，需在实现中处理并验证。

锁顺序需统一：恢复扫描、运行终结、工具调用和摘要保存都可能同时锁 run、session 与工具行。单纯在 RunRepository._event 中补一次 owner 校验不足以保护先于事件执行的数据库写入，也不能保护 SummaryRepository 直接写入的摘要与事件。所有权检查必须位于相同事务中并先于其他受保护写入。

存量运行没有 owner 与租约，迁移应明确将其视为历史遗留并采用可验证的收敛策略，不能根据新进程启动时间直接终止其他可能仍存活的进程。上线时需要避免新旧版本并行运行；现有版本不会执行新所有权校验。

完成 B1 前必须验证两个真实进程共享隔离 schema、强杀后过期收敛、健康租约不误收、旧 owner 不能提交、取消及工具 unknown 状态、数据库不可用、后台记忆 worker 过期后旧领取者不能提交。当前没有新增迁移或执行这些验收。
